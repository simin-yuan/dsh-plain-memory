# 每日巩固（DSH 原生定时会话用）

把下面整段作为 DSH `schedule` 每日任务的提示词。它跑在**普通会话**里，不需要记忆插件参与任何代码路径——插件只负责平时的读写，巩固是模型加文件工具的活。

---

你要为我的记忆仓做一次每日巩固。仓库路径：`<MEMORY_REPO_PATH>`（若不确定，先 `git -C <路径> rev-parse --show-toplevel` 确认）。

**闸门（先做这一步）**：看 `.state/last-consolidate` 里记的上次巩固时间；再数 `episodic/` 下修改时间晚于它的文件。
如果**没有新增**，只回一行「无新经历，今日不巩固」然后结束——不要 pull、不要提交、不要读别的文件。
如果有新增，把这次时间写进 `.state/last-consolidate`，继续下面步骤。

**保密（硬规则，优先于其它所有步骤）**：`self.md` 里标为商业机密的范围（例如某条「不写入记忆」的约束），其具体内容一律不提炼、不概括、不写进任何一层记忆；已经存在的直接删掉。只允许保留不含细节的事实，例如「讨论过某个主题」。宁可不记，也不要留可推断的细节。

1. **同步**：`git pull --ff-only`。若失败（离线/冲突），停下并在结论里说明，不要强推。
2. **读**：读 `self.md`、上次巩固之后新增的 `episodic/*.md`、以及 `semantic/` 下所有文件的标题与 `cues` 行。
3. **合并**：把重复或高度重叠的语义条目合并成一条（保留最早日期，`related` 取并集，保留较新的正文）。情景记忆不合并，只删掉完全是噪声的条目。
4. **冲突**：两条记忆互相矛盾时，以更新的、且能追溯到具体会话的那条为准；被推翻的那条删掉并在新条目正文里写一句「推翻了 X（YYYY-MM-DD）」。
5. **遗忘**：删掉已经过期、或被后来事实否定、或只对一次性任务有意义的条目。宁可少，不要留噪声。
6. **提炼线索词**：这是跨领域唤起的主要手段，概念桥只是兜底。每条语义/自我记忆的 `cues` 控制在 3–8 个，写法是「我以后会怎么问这件事」，不是「这条记忆里出现了哪些词」：
   - 抽象概念优先：可复现、降低验证成本、评审、信任、卡住、并发；
   - 带上口语说法：转圈、换电脑、同时、一直等；
   - 跨领域的条目补一条 `related` 指向最相关的另一条。
   - 不要靠往插件词表里加近义词解决召回——词表有上限。
7. **自我层**：只有当最近的情景记忆里出现了稳定的偏好或约束（至少两次），才提议改 `self.md`。把提议原文列在结论里，**等我确认**；不要自己直接改。
8. **提交**：`git add -A && git commit -m "consolidate: YYYY-MM-DD" && git push`。推送失败就保留本地提交并说明。

结论用不超过 8 行汇报：合并了几条、删了几条、改了哪些 `cues`、有没有需要我确认的自我层提议、推送是否成功。
